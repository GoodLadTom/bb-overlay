## How to open a pull request

1. Fork the repository and make a branch for your change.
2. Keep it small and focused: one fix or one feature per pull request.
3. In the description, say what it changes and why, which bb version you tested it on (for example bb 0.46) and which operating system (for example macOS 26 or Ubuntu 24.04).
4. Tick the box in the pull request template to confirm you agree to the terms above.
